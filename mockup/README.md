# Mockup navegável do DegustAR

Protótipo local para demonstrar o fluxo do projeto no vídeo pitch. Ele não depende do Unity, de câmera ou de instalação.

## Como abrir

Abra `index.html` em um navegador moderno. Para evitar limitações do navegador ao abrir arquivos locais, também é possível servir a pasta com um servidor HTTP estático.

## Fluxo recomendado para a gravação

1. Mostre a tela inicial e os três pratos do catálogo.
2. Clique em **Escanear etiqueta**.
3. Clique em **Simular leitura** e aguarde o reconhecimento.
4. Mostre a visualização ilustrativa em 3D, os nutrientes e os alergênicos.
5. Clique em **Avaliar experiência** para mostrar o questionário SUS.

Os dados dos pratos foram transcritos de `Assets/App/Resources/menu_catalog.json`. O protótipo deixa explícito que a leitura e a visualização são simulações.
